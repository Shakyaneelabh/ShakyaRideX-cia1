# 🚗 Shakya RideX – CIA 1 WebStack Project

A premium luxury car rental platform developed as part of the CIA 1 WebStack Project for the Bachelor of Computer Applications (BCA) at CHRIST (Deemed to be University).

---

## 📖 About the Project

Shakya RideX is a modern web-based car rental platform that enables users to browse, compare, and book premium vehicles with ease. The system also provides an admin dashboard for managing vehicles, bookings, and customers.

---

## ✨ Features

- 🚗 Browse luxury cars
- 📅 Online booking system
- 👤 User Dashboard
- ⚙️ Admin Dashboard
- 💳 Booking Management
- 📍 Location Details
- 📞 Contact Support

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- PHP
- MySQL
- VS Code
- GitHub
